# Specification

| Version | Status | Date |
|---|---|---|
| [Base91z v0.4.0](base91z-v0.4.0.md) | Final | 2026-08-31 |

**Base91z v0.4.0 is the current specification and the one to implement.** It is
final: the wire format it defines will not change, and a change that would break
a stream encoded against it is a new version, not an amendment to this one.

Versions it supersedes are kept, and listed under
[superseded specifications](history/README.md). They are there so a decision can
be traced to the document that made it; nothing should be implemented from them.
